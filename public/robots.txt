# Woogidex

# Ordinary search engines are welcome: being findable is the point of a public
# gallery. What is not welcome is bulk collection of other people's artwork,
# so the crawlers below -- the ones that exist to harvest images and text for
# model training or to resell scraped content -- are refused outright.
#
# NOTE: robots.txt is only honoured at the root of a domain. If this site is
# served from a GitHub Pages project path (woogi999.github.io/woogidex/), then
# crawlers read woogi999.github.io/robots.txt and never see this file -- it has
# to live in the user-pages repo instead. The <meta name="robots"> tag in
# index.html applies either way.
#
# This file is a request, not a fence. A crawler that ignores robots.txt will
# ignore this too. It is here because the well-behaved majority do honour it,
# and because a written refusal is what makes later action possible.
